# Cad-lite documentation

The map of the library. Start here, find the one or two documents your task needs, and stop reading.
The product is an AutoCAD-style 2D drafting application written in Go; the code lives beside this
folder, and the UI framework under it has its own library at `internal/gpui/_docs/`.

**The duty.** A change that touches code, behaviour or a contract updates the documents it touched
in the same commit. Everything needed to do that is in [`_meta/authoring.md`](_meta/authoring.md);
`go run ./tools/docs touched` names the documents your diff touches.

| Path | Holds |
|---|---|

| `_meta/` | How this library works: [authoring](_meta/authoring.md), [librarian](_meta/librarian.md), the proposal ledger and the review log |
